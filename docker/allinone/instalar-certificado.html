Conexión segura con Woow Kids

La caja, el punto de venta y la cámara del registro solo funcionan por una conexión segura (HTTPS). Cada computadora, tableta o teléfono que use el sistema debe confiar una sola vez en el certificado de esta instalación.

1. Descargar el certificado 2. Abrir Woow Kids (HTTPS)

Antes de instalarlo, comprueba que su huella digital (SHA-256) sea esta:

__HUELLA__

Este servidor usa un certificado de tu organización. Si tu equipo pertenece al dominio, no hay que instalar nada: abre Woow Kids directamente.

Abrir Woow Kids (HTTPS)

Windows (Chrome o Edge)

  1. Abre el archivo certificado-woowkids.crt descargado y elige Instalar certificado…
  2. Ubicación del almacén: Equipo local (pide permiso de administrador).
  3. Elige Colocar todos los certificados en el siguiente almacén → Entidades de certificación raíz de confianza → Aceptar → Siguiente → Finalizar.
  4. Cierra por completo el navegador y vuelve a abrirlo.

En una red con dominio, el área de sistemas puede repartirlo a todas las computadoras por directiva de grupo (GPO).

macOS

  1. Abre el archivo descargado: se agrega a Acceso a Llaveros (llavero Sistema).
  2. Haz doble clic en «Woow Kids CA local», abre Confiar y elige Confiar siempre.

Android

  1. Ajustes → Seguridad → Cifrado y credenciales → Instalar un certificado → Certificado de CA.
  2. Elige el archivo descargado y confirma.

iPhone o iPad

  1. Abre esta página en Safari y descarga el certificado; acepta instalar el perfil.
  2. Ajustes → General → VPN y gestión de dispositivos → instala el perfil «Woow Kids».
  3. Ajustes → General → Información → Configuración de confianza de certificados → activa «Woow Kids CA local».
